The Void Throne — Project Index and Working Agreement

Project home

The Void Throne now has a separate local game repository at C:/AnalogueGames/void-throne and a dedicated Google Drive folder. The older Obsidian and GameSpec folders remain untouched. Their relevant sources are preserved in the new repository with checksums.

[WORKING] The current design is the five-player, two-round paper prototype with revised vision timing, three foresight tokens, voluntary Standing Commitments and weighted final settlement. The browser and Playtrace are development tools; neither is required to play the paper game.

Start testing

Run launch.py from the repository, or use Start Playtest.cmd. The local browser opens at http://127.0.0.1:8877. Control every seat, record reasons, commit assets, enter council orders and cast votes. It saves the last completed sheet locally. Download HTML and JSON before starting another test. You can resume an exported decision record.

Run playtrace_game.py reproduce using the Playtrace Python environment to build the source snapshot, deterministic replay, report and hypothesis-linked experiment bundle. Run the game’s tests before changing printed consequences. The exact command and dependency path are in README.md.

For a fresh LLM game, use the information-boundary protocol in design/experiments/agent-protocol.md and record original decisions. The retained six-agent run is ready for inspection; a deterministic replay is not a fresh conversation.

First design questions

Will the Ascendant deliberately decline a purchase? Does the army accept a settlement imposed by a valid weighted coalition? Do provisional powers change preferences, or merely confirm them? Does the Guild sacrifice enough in the reserve-supported path? Can people finish the discussion and signatures on time?

The current code implements the accepted experimental rules. New balance proposals remain proposals until the designer chooses them. No statistical claim of success follows from one agent run.
