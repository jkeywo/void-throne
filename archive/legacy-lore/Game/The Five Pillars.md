The empire's stability is tracked via five public Pillars, each rated **1–6** and starting at **4**. All players can see all Pillar values at all times.

---

| Pillar | Primary Stewards | What It Tracks |
|---|---|---|
| **Martial Authority** | [[Janissariat High Command\|Janissariat]], Ascendant | Garrison statistics across all systems |
| **Spiritual Cohesion** | [[Ecclesiatum Perpetua\|Ecclesiatum]] | Loyalty and Faith statistics |
| **Economic Flow** | Noble Houses, [[Ductus Guild]] | Output statistics and open void lanes |
| **Administrative Order** | [[Administratum]] | Order statistics |
| **Void Integrity** | [[Ductus Guild]] | Open void lane count |

---

## Pillar Events

| Threshold | Effect |
|---|---|
| Drops to **1** | **Crisis Event** triggers — a specific, severe consequence all factions must contend with |
| Reaches **6** | **Stability Dividend** — a positive event benefiting whoever stewarded it there |

## Pillar Feeds

Statistic values across all systems aggregate upward to their Pillar at the end of each round. Control manages this calculation and updates the board publicly.

Each system has a Garrison statistic (feeds Martial Authority) plus up to three of the following:

| Statistic | Feeds |
|---|---|
| Loyalty | Spiritual Cohesion |
| Output | Economic Flow |
| Faith | Spiritual Cohesion |
| Order | Administrative Order |

See [[Systems Overview]] for per-system statistic assignments.
